Copy `KUNTAU_TERRAPULSE_V1.0.0.zip` into your Windows Downloads folder, open **Command Prompt (CMD)**, and paste this single line:

```cmd
powershell -NoProfile -ExecutionPolicy Bypass -Command "$zip = Join-Path $env:USERPROFILE 'Downloads\KUNTAU_TERRAPULSE_V1.0.0.zip'; if (!(Test-Path -LiteralPath $zip)) { throw 'ZIP not found in Downloads' }; Expand-Archive -LiteralPath $zip -DestinationPath (Join-Path $env:USERPROFILE 'Desktop') -Force" && call "%USERPROFILE%\Desktop\KUNTAU_TERRAPULSE_V1.0.0\PUBLISH_TO_GITHUB_MAIN.bat"
```

The script uses the existing clone at `%USERPROFILE%\Desktop\KUNTAU-TERRAPULSE`. It verifies the origin URL, pulls `main` with fast-forward only, refuses a dirty local clone, shows the changes, and requires you to type `YES` before committing and pushing.
