# KUNTAU TERRAPULSE v0.8.2 — Mobile Earth Intelligence Studio

A mobile-first Earth-observation workspace built by the KUNTAU Science and Engineering Team at KUNTAU Science Academy.

- Application: `app/`
- Android installation and PWA launch repair: `INSTALL_ON_ANDROID.md`
- Release notes: `RELEASE_NOTES_V0.8.2.md`
- GitHub publishing script: `PUBLISH_TO_GITHUB_MAIN.bat`
- One-command extraction and publish: `CMD_EXTRACT_AND_PUBLISH.txt`

Cloudflare Pages settings: production branch `main`; root directory `app`; build command `exit 0`; output directory `.`. Install the phone PWA only from the live HTTPS Cloudflare Pages address. The Windows `127.0.0.1` local preview is for the computer only.

Do not commit original HDF5/GeoTIFF research sources or Earthdata credentials. Packaged raster PNGs are labelled exploratory and do not constitute a validated flood or crop-damage classification.
