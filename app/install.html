ANDROID · INSTALL & LAUNCH

Bring the Earth Intelligence Studio to your home screen.

Install the live TERRAPULSE website as a standalone Progressive Web App. It opens like an app window, with the KUNTAU badge and no ordinary browser address bar.

Why the old icon could not reach the site

The Windows preview address 127.0.0.1 points back to the computer itself. A phone cannot use that address to reach the computer. Install the phone version from the public HTTPS Cloudflare website instead.

FOUR QUICK STEPS
01

Remove the previous icon

Long-press the old TERRAPULSE home-screen icon and choose Remove or Uninstall. This clears the old saved launch address.

02

Open the live HTTPS website

Use Chrome on the phone and open the deployed Cloudflare Pages or custom-domain address. It must begin with https://. Do not use a downloaded HTML file, localhost or 127.0.0.1.

03

Install the app

Open Chrome’s three-dot menu and choose Install app or Add to Home screen. Confirm the prompt.

04

Launch the KUNTAU badge

Open the new KUNTAU TERRAPULSE icon. It should launch in its own app window. If the website has not deployed yet, wait until Cloudflare shows a successful deployment, then repeat steps 1–4.

TERRAPULSE is a Progressive Web App (PWA), not an Android APK from Google Play. HTML, CSS and JavaScript are the files used by the browser to render the interface; users see the finished application, not the source code. The 3D globe and map controls need an internet connection to load their specialist libraries. Included preview and explanatory content remain available through the app shell once cached.
